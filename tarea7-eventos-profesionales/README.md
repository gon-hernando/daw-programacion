# 📅 Eventos profesionales

> 📚 Práctica 07 · **Programación** · 2.º DAW

Aplicación desarrollada en **Java** para la gestión de eventos profesionales, participantes y recursos. El proyecto se ejecuta por consola y utiliza diferentes conceptos de programación orientada a objetos.

## 📖 Descripción

El programa permite gestionar eventos profesionales y los diferentes participantes y recursos asociados a cada evento mediante un menú interactivo por consola.

La aplicación está organizada mediante diferentes clases, interfaces y paquetes para separar las responsabilidades relacionadas con los eventos, participantes, recursos y la interacción con el usuario.

## ✨ Funcionalidades

- 📅 Gestión de eventos
- 🙋 Gestión de participantes
- 🧑‍💼 Gestión de diferentes perfiles de participantes
- 🧰 Gestión y asignación de recursos
- 📋 Consulta de información de eventos
- 🔎 Gestión de participantes y recursos asociados
- 🖥️ Menú interactivo por consola
- ✅ Validación de los datos introducidos

## 🎯 Conceptos trabajados

## 🚀 Cómo ejecutar el proyecto

El proyecto está preparado para ejecutarse como proyecto de **Apache NetBeans**.

### 1. Clonar el repositorio

    git clone https://github.com/gon-hernando/daw-programacion.git

### 2. Abrir el proyecto

Desde **NetBeans**:

1. Seleccionar **File → Open Project**.
2. Buscar la carpeta `tarea7-eventos-profesionales`.
3. Abrir el proyecto.

### 3. Ejecutar

Ejecutar el proyecto desde NetBeans.

La clase principal es:

    clases.Main

Al iniciar la aplicación se mostrará el menú principal por consola.

## 🕹️ Uso

La aplicación funciona mediante un menú interactivo en consola.

El usuario selecciona las diferentes opciones disponibles introduciendo el número correspondiente y sigue las instrucciones mostradas por el programa.

## 📚 Objetivo

Esta práctica forma parte de la asignatura **Programación** del ciclo de **Desarrollo de Aplicaciones Web (DAW)** y permite trabajar conceptos avanzados de programación orientada a objetos mediante la gestión de eventos, participantes y recursos profesionales.

Entre los conceptos trabajados destacan la **herencia**, las **interfaces**, las **clases genéricas** y la relación entre diferentes entidades dentro de una aplicación.
