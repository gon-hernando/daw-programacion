# 🏦 Aplicación bancaria

> 📚 Práctica 05 · **Programación** · 2.º DAW

Aplicación desarrollada en **Java** para la gestión de clientes y cuentas bancarias. El proyecto se ejecuta por consola y está organizado siguiendo los principios de la programación orientada a objetos.

## 📖 Descripción

El programa permite gestionar clientes y sus cuentas bancarias mediante un menú interactivo por consola.

La aplicación está organizada en diferentes clases y paquetes para separar las responsabilidades relacionadas con los clientes, las cuentas, la gestión de la aplicación y la interacción con el usuario.

## ✨ Funcionalidades

- 👤 Gestión de clientes
- 💳 Gestión de cuentas bancarias
- 📝 Registro y consulta de información
- 💰 Gestión de operaciones bancarias
- 🔎 Consulta de cuentas y datos asociados
- 🖥️ Menú interactivo por consola
- ✅ Validación de los datos introducidos

## 🎯 Conceptos trabajados

- ☕ Programación orientada a objetos (POO)
- 📦 Clases y objetos
- 🔒 Encapsulación
- 🔗 Relaciones entre objetos
- 🗂️ Organización mediante paquetes
- 📋 Gestión de colecciones
- 🔄 Estructuras de control
- ⌨️ Entrada de datos por consola
- 🧩 Métodos y modularización
- ⚠️ Validación y gestión de errores

## 🚀 Cómo ejecutar el proyecto

El proyecto está preparado para ejecutarse como proyecto de **Apache NetBeans**.

### 1. Clonar el repositorio

    git clone https://github.com/gon-hernando/daw-programacion.git

### 2. Abrir el proyecto

Desde **NetBeans**:

1. Seleccionar **File → Open Project**.
2. Buscar la carpeta `tarea5-app-bancaria`.
3. Abrir el proyecto.

### 3. Ejecutar

Ejecutar el proyecto desde NetBeans.

La clase principal es:

    AplicacionCuentaBancaria

Al iniciar la aplicación se mostrará el menú principal por consola.

## 🕹️ Uso

La aplicación funciona mediante un menú interactivo en consola.

El usuario selecciona las diferentes opciones disponibles introduciendo el número correspondiente y sigue las instrucciones mostradas por el programa.

## 📚 Objetivo

Esta práctica forma parte de la asignatura **Programación** del ciclo de **Desarrollo de Aplicaciones Web (DAW)** y permite trabajar la programación orientada a objetos mediante el desarrollo de una aplicación de gestión de clientes y cuentas bancarias.
