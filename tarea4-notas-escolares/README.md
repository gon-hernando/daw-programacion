# 📚 Notas escolares

> 📚 Práctica 04 · **Programación** · 1.º DAW

Aplicación desarrollada en **Java** para la gestión de estudiantes, asignaturas, matrículas y calificaciones. El proyecto se ejecuta por consola y está organizado siguiendo los principios de la programación orientada a objetos.

## 📖 Descripción

El programa permite gestionar información relacionada con estudiantes y asignaturas, así como las matrículas y calificaciones asociadas a cada estudiante.

La aplicación está organizada en diferentes clases y paquetes para separar las responsabilidades y facilitar la gestión de la información.

## ✨ Funcionalidades

- 🧑‍🎓 Gestión de estudiantes
- 📚 Gestión de asignaturas
- 📝 Gestión de matrículas
- 💯 Registro y gestión de calificaciones
- 📊 Consulta de información académica
- 🖥️ Menú interactivo por consola
- ✅ Validación de los datos introducidos

## 🎯 Conceptos trabajados

- ☕ Programación orientada a objetos (POO)
- 📦 Clases y objetos
- 🔗 Relaciones entre objetos
- 🔒 Encapsulación
- 🗂️ Organización mediante paquetes
- 📋 Gestión de colecciones
- 🔄 Estructuras de control
- ⌨️ Entrada de datos por consola
- 🧩 Métodos y modularización
- 📊 Operaciones y cálculos con datos académicos
- ✅ Validación y gestión de errores

## 🚀 Cómo ejecutar el proyecto

El proyecto está preparado para ejecutarse como proyecto de **Apache NetBeans**.

### 1. Clonar el repositorio

    git clone https://github.com/gon-hernando/daw-programacion.git

### 2. Abrir el proyecto

Desde **NetBeans**:

1. Seleccionar **File → Open Project**.
2. Buscar la carpeta `tarea4-notas-escolares`.
3. Abrir el proyecto.

### 3. Ejecutar

Ejecutar el proyecto desde NetBeans.

La clase principal es:

    Main

Al iniciar la aplicación se mostrará el menú principal por consola.

## 🕹️ Uso

La aplicación funciona mediante un menú interactivo en consola.

El usuario selecciona las diferentes opciones disponibles introduciendo el número correspondiente y sigue las instrucciones mostradas por el programa.

## 📚 Objetivo

Esta práctica forma parte de la asignatura **Programación** del ciclo de **Desarrollo de Aplicaciones Web (DAW)** y permite trabajar la programación orientada a objetos mediante la creación y gestión de diferentes entidades relacionadas con el ámbito académico.
