# ⚽ Registro de deportes

> 📚 Práctica 02 · **Programación** · 1.º DAW

Aplicación desarrollada en **Java** para la gestión de participantes inscritos en diferentes deportes. El proyecto se ejecuta por consola y está organizado siguiendo una estructura basada en programación orientada a objetos.

## 📖 Descripción

El programa permite gestionar diferentes deportes y los participantes inscritos en ellos mediante un menú interactivo por consola.

El proyecto está organizado en diferentes clases y paquetes para separar las responsabilidades de la aplicación y facilitar su mantenimiento.

## ✨ Funcionalidades

- ➕ Gestión de deportes
- 👤 Registro y gestión de participantes
- 🏅 Inscripción de participantes en deportes
- 📋 Consulta de información
- 🖥️ Menú interactivo por consola
- ✅ Validación de datos introducidos por el usuario

## 🎯 Conceptos trabajados

- ☕ Programación orientada a objetos (POO)
- 📦 Clases y objetos
- 🔒 Encapsulación
- 🗂️ Organización mediante paquetes
- 📋 Colecciones
- 🔄 Estructuras de control
- ⌨️ Entrada de datos por consola
- 🧩 Métodos y modularización
- ✅ Validación y gestión de errores

## 🚀 Cómo ejecutar el proyecto

El proyecto está preparado para ejecutarse como proyecto de **Apache NetBeans**.

### 1. Clonar el repositorio

    git clone https://github.com/gon-hernando/daw-programacion.git

### 2. Abrir el proyecto

Desde **NetBeans**:

1. Seleccionar **File → Open Project**.
2. Buscar la carpeta `tarea2-registro-deportes`.
3. Abrir el proyecto.

### 3. Ejecutar

Ejecutar el proyecto desde NetBeans.

La clase principal es:

    ligadeportesalternativos.LigaDeportesAlternativos

Al iniciar la aplicación se mostrará el menú principal por consola.

## 🕹️ Uso

La aplicación funciona mediante un menú interactivo en consola.

El usuario selecciona las diferentes opciones disponibles introduciendo el número correspondiente y sigue las instrucciones mostradas por el programa.
